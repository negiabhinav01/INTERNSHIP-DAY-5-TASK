# INTERNSHIP-DAY-5-TASK

Titanic Survival Analysis - Data Visualization Project

Overview

This project focuses on analyzing the Titanic dataset to explore the patterns and relationships that influenced passenger survival. Using Python and data visualization libraries like Matplotlib and Seaborn, we investigate various factors such as gender, class, age, fare, and more.

Objective

To derive meaningful insights from the Titanic dataset by creating clear, informative visualizations and performing exploratory data analysis (EDA).

Dataset
	•	Source: Kaggle Titanic
	•	Files Used: test.csv, train.csv

Key Analyses & Visualizations
	•	Distribution of survivors vs. non-survivors
	•	Survival rate by gender
	•	Impact of passenger class on survival
	•	Age and fare distributions
	•	Survival based on port of embarkation
	•	Correlation heatmaps
	•	Any other specific plots created in the notebook

Technologies Used
	•	Python
	•	Jupyter Notebook
	•	Pandas
	•	Matplotlib
	•	Seaborn

How to Run
	1.	Clone this repository
	2.	Open the Jupyter Notebook: Plots_Titanic_test.ipynb
	3.	Run the cells in order to generate the visualizations
 
Conclusion
This analysis provides a foundational understanding of key factors influencing survival on the Titanic, showcasing the power of EDA and data visualization in uncovering insights from data.
